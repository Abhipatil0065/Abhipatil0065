## 🚀 Projects

### 🤖 Jobaplayer: AI Job Application Agent
An automation agent that scans X (Twitter) for hiring posts, classifies them, and automatically sends my portfolio and resume by DM or email.
- Keyword-based post classification and email extraction
- Selenium browser automation for login, scraping, and messaging
- Gmail SMTP integration with resume attachment
- SQLite database for duplicate prevention and tracking
- Flask dashboard showing total, daily, and recent application stats
- **Tech:** Python, Selenium, SQLite, Flask, SMTP
